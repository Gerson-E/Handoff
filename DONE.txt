================================================================================
                             IMPORTANT NOTES
================================================================================

1. Both services will auto-restart if code changes (due to --reload flags)

2. Frontend and backend communicate via API calls
   - Frontend uses VITE_API_BASE environment variable
   - All API calls include x-api-key header

3. Database is SQLite for development
   - Perfect for local development
   - Can migrate to PostgreSQL for production

4. Patient IDs patient-00000 to patient-00099 are pre-seeded
   - Try any ID in this range
   - Format: patient-##### where ##### is 00000-00099

5. Make sure ports 3000 and 8000 are not in use
   - Check: lsof -i :3000 and lsof -i :8000
   - Or change ports in npm run dev or uvicorn commands
